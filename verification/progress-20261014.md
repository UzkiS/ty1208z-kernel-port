无线 attach 崩溃、握手 IE、热点 GTK、USB 发送补齐和 RTNL 内模块重载问题已修复。
网络重载导致管理中断的原因是 netifd 在 EOF 后无限读取；已修复、编包并恢复有线管理。
详见[无线实机报告](rda-wireless-board-20261014.md)。

盒子目前运行较大内存的整合 RAM 系统。临时无线测试网络已清理，无线默认关闭，
有线管理正常，root 默认空密码；COM9 没有活动监听。本轮未刷闪存、未改持久 boot，
未写 SD/eMMC 数据。

最终本地私有交付为 22,987,418 字节 bootstrap 和 103,696,571 字节补充包；
全部 8 个清单文件已同步校验。原厂 RDA 固件、原固件和原始日志不公开。
这些是 RAM 开发交付，不能当作可直接刷写的正式固件。

剩余工作集中在持久化：可写存储支持、完整 rootfs/启动镜像、安装布局与恢复流程，
以及安装后配置和 Docker 数据跨重启保留。正式写入前还需针对具体镜像取得授权。
方向与未满足条件见[安装准备方案](../docs/installation-plan.md)。
既有内存、网络、Docker、代理和 time64 验证不重复，不将推断覆盖写成新增实测。
