## Earlier attempts and the low reservation

The first image passed boot but could not mount its tmpfs: minimal BusyBox
did not parse the added nosuid/nodev/noexec flags as mount flags. Removing
those options and exercising real ARM mount/low-memory denial/cleanup in
isolated QEMU corrected the script. That first image did not run memory stress.

The next image passed both full 512-MiB data patterns but failed the strict
PFN boundary check. A distinct instrumented image located page zero at PFN
1495 (0x005d7000). Its exact System.map places the kernel init area at
0x00400000..0x00600000. ARM normally frees its own init pages, even inside
the DT reservation; the dedicated memory profile now retains that init area.
Generic and ordinary native-router reclamation remain unchanged. Actual
patched free_initmem tests cover the selected/unselected configuration,
matching/foreign board and Integrator exceptions under ASan/UBSan.

The accepted image above was rebuilt, independently transferred/device-CRC
checked and physically retested after retention was added. Earlier boot/data
results are not relabeled as full physical-memory acceptance. Their manifests,
raw evidence and payloads remain local and ignored.

## Autonomous return and validation

The exclusive UART tool checks exact kernel/DT identity, bound reset driver,
measured inactive watchdog registration and removal of the memory file/mount.
One command restart returns to Boot ROM/DDR/CA Fastboot; no reset retry is
used. Fresh inspection precedes retransfer of the original router kernel and
initrd, with two independent device CRCs. All 14 selected
configuration/account/key hashes are restored, root remains empty, real
blank-root login reaches Chinese LuCI/Passwall, IRQ Err0 and the original
exact-kernel restart module is registered again. Returned health stream SHA:
`33809ff2cb5e20801e80a75f3525a7116c3ac43670bc6871b66bca35aa464c09`.

Return management setup initially checked before DHCP was ready: link came
up around 52 seconds and a lease followed, after the 45-second boot capture.
A read-only observation established link/address/DNS; the setup helper now
waits for a unique lease with a bounded loop before restoring management.
Configuration/module/web restoration then passed without another reboot or
user intervention. This does not establish arbitrary network-failure recovery.

Core make lint/build/test, updated serial PTYs, memory image/config/layout/
