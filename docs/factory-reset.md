# 恢复默认设置

从 `2026.10.15.3` 起，已安装的 eMMC 系统支持恢复默认配置，无需重新下载或刷写固件。
在 LuCI 打开“系统 → 恢复默认设置”，点击“恢复默认设置”，确认后会自动重启。
旧版需先通过“系统 → 备份与更新”升级 sysupgrade 包。

`2026.10.15.5` 修复了预检成功时按钮仍呈灰色的前端问题。页面地址为
`/cgi-bin/luci/admin/system/reset`，原 `/admin/system/ty1208z-reset` 地址保留兼容入口。

命令行等价操作：

```sh
firstboot -y -r
```

`factoryreset -y -r`、`jffs2reset -y -r` 和 `ty1208z-reset -y -r` 使用同一板级后端。
不带 `-y` 会要求交互确认；不带 `-r` 只安排重置，在下次正常重启时执行。
`ty1208z-reset --check` 仅预检，不修改配置。已有待执行事务时应先重启完成，不能同时升级固件。

## 清除和保留范围

整个 `/etc` 恢复为当前固件的默认内容，清除系统/网络/无线配置、root 管理密码、
SSH 登录授权、自定义启动与计划任务、挂载设置、代理和服务配置。`/root/.ssh/authorized_keys`
与 `authorized_keys2` 也会删除。软件文件和 APK 安装记录保留；后装软件在 `/etc` 中新增的
配置、启动脚本会被清除，可能需要重新配置或安装。

保留本机 Ethernet MAC 和 SSH 主机密钥；主机密钥用于识别设备，不提供登录授权。
保留 SD/USB 文件、`/opt/docker` 镜像和容器数据，以及 `/root`、`/home`、`/mnt`、`/srv`
中的用户文件，登录授权文件除外。挂载规则恢复默认后，需要重新设置自动挂载；容器服务配置
也恢复默认，数据保留不等于原来的所有服务自动运行。

不格式化 p9，不写入 p6、引导器、其他 eMMC 分区或安全状态。这里只恢复配置，
不会把已安装的软件和整个系统文件回滚成出厂镜像；修复系统文件应使用 sysupgrade 包。

## 重置后的连接

默认账号 `root`，空密码。Wi-Fi 热点为 `TY1208Z`，无密码。
重置恢复所安装固件类型的快照，不会恢复升级前保留的旧网络类型：

- `bridge`：Wi-Fi 与网口桥接，由主路由分配同网段管理地址。连接热点或原有线网络后，
  尝试原来的管理地址，或在主路由客户端列表查询盒子的租约。
- `hybrid`：无线独立 NAT，连接热点访问 `http://192.168.50.1/`，也可使用盒子的有线地址。
- `nat`：连接热点访问 `http://192.168.50.1/`，默认不允许从上级有线网络访问管理服务。

网络布局和切换方式见[网络版本说明](network-variants.md)。
本机 MAC 保持稳定有助于沿用上级租约，有线地址仍由主路由决定，需要固定 IP 时设置 DHCP 地址保留。

LuCI 会尝试重连当前地址和 `openwrt.lan`。如果之前使用自定义静态地址或其他上联方式，
恢复默认后应按上述类型使用对应管理入口。

## 实现与验证边界

默认配置从公开构建根生成，由真实 APK 保存文件校验和、软链接清单及精确内核 ABI。
后端先验证当前 p9 ext4 根与配置快照，再准备持久事务；下次 preinit 在网络和服务启动前
通过原子目录交换切换 `/etc`。中断发生在交换前使用旧配置，交换后使用完整新配置；
事务标识防止再次启动时交换回旧密码。校验失败时保留串口恢复入口。

首刷包的快照包含对应扩容服务文件，不会抹掉软件包拥有的文件，也不会重新安排首次扩容。
原上游 `factoryreset` 依赖 `rootfs_data`，已通过检查固定版本和文件哈希的 fstools APK
适配接入本板后端，不再对 p9 调用 overlay 擦除逻辑。

LuCI 页面与实际重置 RPC、一次真实恢复默认、数据和身份保留已完成实机验证。
断电事务恢复由隔离目录中的真实原子交换测试覆盖，没有在设备上反复制造掉电。
实体复位键的 GPIO 和长按行为未验收；当前支持入口为 LuCI 和上述命令。
详见[实机记录](../verification/factory-reset-board-20261015.md)。
按钮修复的真实 LuCI DOM 回归、实机页面和预检结果见[页面修复记录](../verification/reset-ui-board-20261015.md)。
三种网络版本各自快照与隔离重置事务检查通过，新混合/NAT 版尚未实机联网验收，
见[三版离线记录](../verification/network-variants-20261020.md)。
