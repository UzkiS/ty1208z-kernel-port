# TY1208Z 高安版 fastboot 归档

此目录保存本项目实机已使用成功的高安版引导器，供相同硬件的资料保全与恢复参考。
它是海思板级引导器，不是 Android 主机端的 `fastboot` 命令。

正常安装或升级 OpenWrt 沿用设备现有的可用引导器，**不需要重刷本文件**。
不同 DDR、板型和安全配置的适配未验证，不能仅凭 SoC 名称相同判断兼容。
恢复时仍须核对自己的硬件、现有引导和备份；本仓库没有自动写入 bootloader 的步骤。
